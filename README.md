# 📊 Portfólio de Projetos de Dados: SuperStore (Excel Avançado)

Repositório dedicado a soluções de análise de dados aplicadas ao negócio desenvolvidas para a **SuperStore** (rede fictícia de supermercados)[cite: 1, 2], utilizando **Microsoft Excel** para ETL, modelagem, análise exploratória e criação de indicadores estratégicos para tomadas de decisão.

---

## 📂 Estrutura dos Projetos

### 1. Análise Exploratória de Pedidos e Comportamento de Clientes
* **Contexto do Negócio:** A diretoria da SuperStore precisava integrar dados transacionais dispersos de clientes, localizações, produtos e pedidos para monitorar indicadores unificados e entender o comportamento de compra.
* **Objetivo:** Analisar o volume de pedidos, descrever os produtos mais comercializados, avaliar o tamanho das cestas de compra e gerar insights descritivos para apoiar o abastecimento e as vendas.
* **Ferramentas e Métodos:** Importação e tratamento de dados relacionais (`customers`, `location`, `orders`, `product`), estruturação de bases e construção de dashboards dinâmicos.

### 2. Análise de Cohort para Retenção de Clientes
* **Contexto do Negócio:** A identificação de uma queda na frequência de compras de clientes recorrentes motivou a criação de métricas de acompanhamento temporal.
* **Objetivo:** Medir a retenção de clientes ao longo do tempo através de matrizes de Cohort, identificando o comportamento de engajamento e os pontos de abandono da base.
* **Ferramentas e Métodos:** Tabelas dinâmicas avançadas, agrupamento de datas por safra de aquisição (Cohort) e cruzamento de dados transacionais para rastreamento de recorrência.

### 3. Segmentação de Clientes (Matriz RFM)
* **Contexto do Negócio:** Com diferentes níveis de retenção entre os Cohorts, a gerência precisava direcionar ações de marketing e produto para públicos específicos, mas carecia de uma segmentação estruturada da base.
* **Objetivo:** Segmentar os clientes utilizando a metodologia **RFM** (Recência, Frequência e Valor monetário), criando grupos menores com necessidades específicas para campanhas direcionadas.
* **Ferramentas e Métodos:** Modelagem de dados, fórmulas lógicas e estatísticas do Excel para pontuação de clientes, estruturação de personas de consumo e proposição de estratégias para Marketing, Vendas e Produtos.

---

## 🛠️️ Tecnologias e Habilidades Demonstradas
* **Microsoft Excel Avançado:** Tratamento de dados, Tabelas Dinâmicas, Funções de Busca/Referência e Lógicas Condicionais.
* **Análise de Dados de Negócios:** Indicadores de desempenho (KPIs), comportamento do consumidor, análise de retenção (Cohort) e segmentação comportamental (RFM).
* **Data Storytelling:** Tradução de dados transacionais em insights acionáveis para as áreas de Marketing, Vendas e Operações.
